SAKTHI BALAN R — DATA SCIENCE PORTFOLIO

FILES
- index.html: website content
- style.css: responsive visual design
- script.js: mobile navigation menu

PREVIEW
1. Download and extract the ZIP.
2. Open the folder and double-click index.html.

PUBLISH WITH GITHUB PAGES
1. Open your GitHub repository (or create a new one).
2. Upload index.html, style.css, and script.js to the repository root.
3. Commit the changes.
4. Go to Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish the site.

Before publishing, verify your LinkedIn/GitHub links and update project descriptions to match the exact status of your work. Add your Data Science course provider when you want it displayed.
